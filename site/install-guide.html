How to install FRIDAY

It takes about two minutes. FRIDAY is installed from a file instead of from Google Play, so Android asks you to say yes a few times. The words below match what Android shows; the wording on your phone can differ a little by brand.

  1. Download the fileOn the download page, tap Download FRIDAY.apk. If your browser warns that this type of file can be harmful, choose to keep it. It is the same file whose checksum is shown on the page.
  2. Allow installs from your browserWhen you open the file, Android may say it blocked the install. Tap Settings, then switch on Allow from this source for the browser or file app you used. Go back.
  3. InstallTap Install. If Google Play Protect asks to scan the app, choose Scan or Install anyway.
  4. Open FRIDAY and agreeFRIDAY explains what phone control does and what is shared. Tap Agree and turn on. Android opens its accessibility settings.
  5. On Android 13 or newer, unlock the switchIf the FRIDAY switch is greyed out, Android is protecting you from apps that did not come from a store. Open Settings → Apps → FRIDAY (the App info page), tap the three dots at the top right, and choose Allow restricted settings. Confirm with your PIN or fingerprint if asked.
  6. Turn FRIDAY onGo to Settings → Accessibility → Installed apps → FRIDAY, switch it on and confirm. Go back to FRIDAY, add your Gemini key when it asks, and say what you want done.
Why accessibility? It is the only way Android lets an app see the screen and tap and type for you. FRIDAY uses it only when you ask it to do something, and you can switch it off at any time in the same place.

If something does not work

  • "App not installed". You may have an older copy signed with a different key. Uninstall it and install again.
  • The switch in Accessibility is still greyed out. Repeat step 5 and make sure you chose Allow restricted settings on the FRIDAY page, not another app.
  • Android turns FRIDAY off by itself. Some phones stop accessibility apps to save battery. Set FRIDAY's battery use to Unrestricted in its App info page.
