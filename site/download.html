Check the file

Every release has a SHA-256 checksum, shown above. After you download the file you can compare it, for example with the free "Hash Droid" app or on a computer with certutil -hashfile FRIDAY.apk SHA256 (Windows) or sha256sum FRIDAY.apk (Linux and macOS). If the two do not match, do not install it.

Updates

Once FRIDAY is installed it checks this site for new versions when you open it. You choose when to download one, and Android asks you to confirm each install.
