# Writing style for F.R.I.D.A.Y.

Every text a user can read in the app, the agreement, the store listing and the website follows these rules.

1. **Say what is true, and only that.** No promise the code does not keep ("never", "always", "100% private"). If something
   is not checked, say it is not checked.
2. **Plain, short sentences.** One idea per sentence. Write the way you would explain it to a friend.
3. **Name things by what the user sees.** "Microphone button", "Settings", "your Gemini key". No internal words such as
   connector, tool call, token, or session unless the screen shows them.
4. **Buttons are verbs.** "Save key", "Clear", "Send report". Not "Submit" or "OK" where a verb fits.
5. **Errors say what happened and what to do next.** "Google did not accept this key. Check that you copied all of it."
6. **No filler and no personality lines.** No jokes, film quotes, "at your service", "set me loose", exclamation marks,
   or emoji. The assistant's voice replies may be warm; the app's text stays neutral.
7. **Same word for the same thing.** The app is "F.R.I.D.A.Y."; the Google service is "Gemini"; the user's key is "your
   Gemini key".
8. **Numbers and limits are exact.** If a limit is 150 memories, write 150 or do not write it.
